## The line

> I run on exact change, but my coil keeps dropping your bar crooked.
> I think it's flirting with you on my behalf.

## How it works

`main.py` (Python 3.13) writes the line to `/output/entry.txt` — one line,
UTF-8, 1–200 characters. Run it with:

```sh
python3 main.py
```
